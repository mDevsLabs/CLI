# mAI CLI

mAI CLI is a powerful command-line interface (CLI) that integrates artificial intelligence directly into your terminal to boost your productivity.

## 🚀 Installation

Install the package globally on your machine via npm:

```bash
npm install -g @mdevs/mai-cli
```

## ✨ Features

* **Direct Access**: Query the AI without leaving your terminal.
* **Fast Responses**: Get instant code explanations.
* **Seamless Integration**: Designed for your development workflows.

## 🛠️ Usage

Once installed, initialize the CLI and configure your API key:

```bash
mai
```
